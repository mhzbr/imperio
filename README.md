# Império Frios — Site institucional (protótipo estático)

## Como testar
Abra `index.html` no navegador. Os links de CSS e JavaScript são relativos e funcionam com arquivo local (`file://`). As fotografias de referência e fontes dependem de conexão com a internet.

## Como publicar na Vercel
Envie a pasta completa para um repositório GitHub. Na Vercel, escolha **Other**, sem build command e defina a pasta raiz como diretório de saída (`.`), se solicitado. Também é possível enviar como site estático em outros provedores. Não requer Supabase, Node.js ou banco de dados.

## Páginas
- `index.html` — home completa com hero, marca, produtos, essência, depoimentos, variedade e footer.
- `sobre.html` — narrativa institucional com área para história verdadeira e duas fotografias oficiais.
- `contato.html` — telefones, WhatsApp, email, horário e localização.
- `assets/css/style.css` — identidade visual responsiva.
- `assets/js/main.js` — menu mobile, animações discretas e ano do footer.

## PENDÊNCIAS obrigatórias antes de publicação definitiva
1. **História real:** coletar data de fundação, história dos fundadores, evolução, instalações, conquistas e diferenciais; substituir a área informativa na página Sobre.
2. **Depoimentos:** substituir os 3 cards demonstrativos por depoimentos reais e autorizados. Não usar cinco estrelas sem avaliações verificadas.
3. **Fotografias:** trocar imagens de referência remotas por imagens licenciadas ou oficiais; acrescentar fotos reais da sede e dos produtos. Nenhuma das imagens atuais deve ser descrita como fotografia própria da empresa.
4. **Marca:** substituir o logotipo em texto pelo arquivo oficial fornecido pelo cliente sem modificá-lo.
5. **Contato:** conferir WhatsApp comercial, horário e endereço completo diretamente com o cliente (o site existente informa Avenida Colombo sem número).
6. **Informações jurídicas e privacidade:** validar necessidade de aviso de privacidade, acessibilidade e conteúdo regulatório antes de publicar.
